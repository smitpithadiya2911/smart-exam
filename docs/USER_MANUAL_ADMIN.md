# Super Admin User Manual

## Overview
The Super Admin has complete control over the platform's academic structure, user directory, exam repository, analytics, reports, announcements, and security audit logs.

### Key Workflows:
1. **Academic Setup**:
   - Navigate to **Departments** -> Click **Add Department** to create faculties.
   - Navigate to **Courses** -> Link degree programs to departments.
   - Navigate to **Semesters** -> Configure start/end dates and terms.
   - Navigate to **Subjects** -> Assign teacher faculty to subjects.

2. **Faculty & Student Directory Management**:
   - Register new teacher accounts with employee IDs.
   - View enrolled students, roll numbers, and delete inactive accounts.

3. **System Reports & Audit Logs**:
   - Download Excel performance reports and PDF exam summaries from **Reports & Analytics**.
   - Review login audit history from **Login History**.
   - Broadcast global announcements to all users from **Notifications**.
