# Teacher User Manual

## Overview
Teachers manage question banks, configure and schedule examinations, conduct random question sampling, and grade subjective/coding answers.

### Key Workflows:
1. **Question Bank Repository**:
   - Navigate to **Question Bank** -> Click **Add Question** for manual entry or **Import Excel** for bulk file upload.
   - Filter questions by subject, difficulty, or question type.

2. **Exam Configuration & Scheduling**:
   - Navigate to **Manage Exams** -> Click **Create New Exam**.
   - Configure title, schedule start/end window, duration in minutes, negative marking rate, and maximum anti-cheat violations.
   - Enter random question sampler count to automatically sample questions from your subject question bank.

3. **Subjective Grading**:
   - Navigate to **Student Results** -> Select an attempt and click **Grade** to evaluate subjective essay or coding responses.
